# PySide6 and Shiboken6 6.11.1 preserved license material

This directory is a structured, byte-preserving copy of all PySide6/Shiboken6
6.11.1 license texts and notices collected from the audited source and wheel
inputs.

- `LICENSES/`: the upstream license alternatives and exception texts.
- `notices/`: PySide6, Shiboken6, libshiboken, and signature notices and
  attribution records.

The original `licenses/PySide6-6.11.1-*` locations remain present. No upstream
notice was removed or rewritten. See `docs/QT-BUILD-PROVENANCE.md` for the exact
wheel/source hashes and `docs/QT-REPLACEMENT-GUIDE.md` for the replacement
procedure.
