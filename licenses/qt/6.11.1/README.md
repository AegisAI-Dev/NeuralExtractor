# Qt 6.11.1 preserved license material

This directory is a structured, byte-preserving copy of the Qt 6.11.1 license
and attribution material already retained by the Neural Extractor audit.

- `LGPL-3.0.txt`: preserved LGPLv3 text.
- `LICENSES/`: all upstream license texts collected for the selected QtBase
  source baseline.
- `attributions/`: all retained upstream `qt_attribution.json` records.

The original `licenses/Qt-6.11.1-*` locations remain present. Duplication is
intentional so older audit manifests remain explainable; no upstream notice was
removed, rewritten, or represented as a project-authored license.

Exact selected binary paths and hashes are recorded in
`docs/QT-BUILD-PROVENANCE.md` and the built candidate's
`QT-PYSIDE-COMPONENTS.json`.
